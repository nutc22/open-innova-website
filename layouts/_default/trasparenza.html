Com'è fatto

  • Le pagine sono generate con Hugo e servite come file statici, senza database né elaborazione applicativa lato server.
  • HTML, CSS e un po' di JavaScript per le interazioni, senza framework.
  • Font di sistema del dispositivo: niente font scaricati da CDN esterne.
  • Hosting statico con distribuzione dei contenuti tramite la CDN del fornitore. Codice e template versionati con Git.
  • Quali dati vengono comunque trattati, per esempio dal servizio di hosting, è spiegato nell'informativa privacy.

Cosa ho scelto di non fare

  • Il sito non imposta cookie.
  • Non integra strumenti di analytics né tracker di terze parti.
  • Non mostra banner per il consenso ai cookie.
  • Non carica font da Google, contenuti incorporati di terze parti o chatbot.
  • Niente localStorage: anche il tema scuro segue l'impostazione del tuo sistema operativo.

Perché lo faccio così

  • Meno risorse da scaricare e meno dipendenze da mantenere: l'essenzialità è una scelta concreta, anche in un progetto piccolo come questo.
  • È lo stesso principio che applico quando progetto sistemi: costruire quello che serve, e niente di più.

How it's built

  • Pages are generated with Hugo and served as static files, with no database or server-side application processing.
  • HTML, CSS and a little JavaScript for interactions, without a framework.
  • Your device's system fonts, with no fonts downloaded from external CDNs.
  • Static hosting, with content delivered through the hosting provider's CDN. Code and templates are version-controlled with Git.
  • The privacy notice explains what data is processed, including by the hosting provider.

What I chose not to do

  • The site doesn't set cookies.
  • It doesn't include analytics tools or third-party trackers.
  • It doesn't display cookie consent banners.
  • It doesn't load Google Fonts, third-party embeds or chatbots.
  • It doesn't use localStorage: dark mode follows your operating system's preferences.

Why I build it this way

  • Fewer resources to download and fewer dependencies to maintain: keeping things simple has practical benefits, even on a project this small.
  • I follow the same principle when designing systems: build what's needed and keep it simple.
